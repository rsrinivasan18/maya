### What We Built

#### 2. AWS Infrastructure (Terraform)
```

Secrets Manager — 6 secrets under /maya/*

```
All resources managed in `infrastructure/main.tf`.

#### 3. WebSocket → HTTP Streaming

**Root cause:** App Runner's Envoy proxy returns `403 Forbidden` on WebSocket upgrade.
Confirmed via: `curl -i -H "Connection: Upgrade" -H "Upgrade: websocket" https://...`

**Solution:**
| Old | New |
|-----|-----|
| `ws://host/ws` persistent connection | `GET /api/session` — init, returns session_id |
| `ws.send(json)` | `POST /chat` — NDJSON streaming response |

Response stream format:
```
{"type": "thinking"}\n
{"type": "response", "text": "...", "intent": "...", "message_history": [...]}\n
```

Client: `fetch() + ReadableStream` decoder replaces WebSocket. `messageHistory` accumulates in browser, sent with each POST. Server echoes updated history in response.

WebSocket endpoint kept in app.py for local dev and future Raspberry Pi use.

#### 4. Pydantic v2 Fix
- `/api/session` returns `session_id` as `int`
- `ChatRequest` had `session_id: str` — Pydantic v2 rejects int→str coercion
- Fix: `session_id: int | str = ""`
